# Tesla-Can-Communication
T2CAN Bench Bridge — a LilyGO T-2CAN sits inline between a Tesla Model 3 charge-port ECU and the X096 vehicle harness, transparently bridging both 500 kbit/s CAN segments while capturing every frame. A PC tool decodes the logs against a Model 3 DBC to reverse-engineer the charge-enable, BMS, and fault messages for reusing the pack.
